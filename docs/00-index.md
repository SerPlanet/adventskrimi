# Doku-Landkarte

Lies nur die Datei, die du für dein Work Package brauchst.

| Du brauchst … | Datei |
|---|---|
| Ziel, Zielgruppen, Nicht-Ziele, Kürzungsreihenfolge | `01-vision-und-scope.md` |
| Spielablauf, Aktionen, Zeitung, Rätsel, Anklage | `02-spielregeln.md` |
| Punkte, Ränge, Plaketten, Frühanklage | `03-punkte-und-wettbewerb.md` |
| Fall-Format, Inhalte schreiben, Profile (Familie/Freunde) | `04-fall-und-inhalte.md` |
| Screens, Zeitstrahl, Raster, Barrierefreiheit | `05-ui-und-barrierefreiheit.md` |
| Stack, Datenmodell, API, Tageslogik, Sicherheit | `06-architektur.md` |
| Solver, Validator, Bots, Qualitätsgrenzen | `07-solver-und-simulator.md` |
| Zeitplan, Reihenfolge, Meilensteine | `08-roadmap.md` |
| Offene Fragen, Entscheidungslog | `09-offen-und-entscheidungen.md` |
| Ablauf pro Work Package, Sub-Agent-Vorlage | `agent/workflow.md` |
| Aufgabenpakete | `wp/WPxx-….md` |
| Aktueller Stand | `STATUS.md` |

Begriffe: **Fakt** = wahre Beobachtung. **Aussage** = Behauptung einer Figur (kann falsch sein). **Fund** = ein Eintrag in der Fallakte eines Spielers. **Quelle** = Ort/Person/Objekt, aus dem man einen Fund bekommt. **Profil** = Konfigurationsvariante (family/friends). **Spieler** = Namenskachel (eine Person oder ein Duo).
